# 参考图索引与使用规则

## 01_abyss_bouquet_reference.jpg

作用：苍渊的材料与光感参考。只看**黑、蓝黑、钢蓝、冰蓝**之间的过渡。

不要采用：绿色枝叶、黄色花芯、背景米白。

关键观察：蓝色不是“贴在黑色旁边”，而像黑色表面受到冷光后自然浮现。

## 02_shirts_colorway_comparison.jpg / 02a_abyss_dark_shirt_reference_crop.jpg

作用：苍渊服装参考。黑色主体 + 灰蓝褶皱，说明颜色应与结构和受光面绑定。

## 03_vallum_light_shirt_reference.png

作用：白垣色彩起点。米白/灰米作为主体，极淡青灰作为褶边和结构性高光。

关键理解：不是“米白 + 薄荷绿”，而是**旧石之白 + 岁月之青**。

## 04_existing_training_platform_reference.png

作用：白垣 UI 的结构基线。保留其极简、列表式、低卡片化、高留白的优点；主要通过 Token 微调完成品牌化。

## 05_generated_abyss_ui_moodboard.png

作用：气氛参考，不是布局模板。可参考黑蓝深度、冷光层次、克制高亮。

## 06_generated_abyss_palette_poster.png

作用：叙事与海报气氛参考。**不得从 AI 生成图中吸色作为精确色值。** 精确色值以 `assets/tokens/` 和 `assets/palette-cards/` 为准。

## 权利与发布提醒

用户提供的商品截图、花束照片等默认作为内部参考素材。若要直接用于公开宣传、广告或商业页面，应先确认图片版权/使用许可。AI 生成参考图可作为内部 moodboard；正式发布仍建议使用自有视觉资产或重新制作的品牌图。
