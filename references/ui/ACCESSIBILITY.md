# 可访问性与对比度

目标：普通正文至少满足 WCAG AA（4.5:1），大字至少 3:1。

已校验的关键组合：

- 苍渊主文字（星笺）`#E7EEF4` / `#080A0D`：约 16.93:1
- 苍渊次文字 `#AAB7C3` / `#080A0D`：约 9.69:1
- 初光 `#9FC4E2` / 深渊 `#080A0D`：约 10.82:1
- 白垣主文字 `#252A2A` / `#F8F7F2`：约 13.56:1
- 白垣次文字 `#656C69` / `#F8F7F2`：约 5.02:1
- 白垣可访问强调文字 `#5D706C` / `#F8F7F2`：约 4.89:1

注意：原始“垣影” `#637774` 在石素背景上约 4.43:1，适合大字、图标、线条和装饰；普通小正文请使用语义 Token `accentStrong = #5D706C`。

## 背景变化时重新检查

上述结论只适用于列出的组合，不能将 Token 名称当作可访问性保证。以下为 v1.1 沿用的语义色值中容易误用的组合：

| 主题 | 前景 / 背景角色 | 对比度 | 普通小字处理 |
|---|---|---:|---|
| 白垣 | textTertiary / bgPrimary | 3.17:1 | 改用 textSecondary |
| 白垣 | textSecondary / selected | 4.37:1 | 改用 textPrimary |
| 白垣 | accentStrong / surfaceSubtle | 4.44:1 | 改用 textPrimary |
| 白垣 | accentStrong / selected | 4.26:1 | 改用 textPrimary |
| 苍渊 | textTertiary / selected | 4.13:1 | 改用 textSecondary |

保持锁定色值，通过调整语义角色解决问题。状态色优先用于图标、边框或标记，状态文字使用满足对比度的文字角色；透明度、叠加背景和 hover/selected 状态都需要按实际渲染重新计算。

输入框应有可访问名称，不能只依赖 placeholder。保留清晰的 `:focus-visible` 外描边，并通过键盘检查。普通正文标准不适用于禁用控件，但不应通过禁用来回避真实操作的可读性问题。

交互状态不能只依赖颜色：选中、错误、成功应同时使用文字、图标、边框或位置变化。
