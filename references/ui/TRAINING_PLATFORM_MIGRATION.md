# 现有训练平台迁移建议

迁移前先检查目标项目的实际页面。对于已有极简、列表式、低卡片化的训练平台，优先保留结构，只给灰色一点色相。

参考 [白垣静态示例](../../assets/examples/vallum_training_platform_demo.html)理解列表与对齐方式；[白垣界面氛围图](../../assets/reference-images/03_vallum_ui_moodboard.png)仅用于材料与光感，不作为平台布局模板。

## 第一阶段：只换 Token

1. 页面背景：纯白/近白 → `#F8F7F2` 石素。
2. Sidebar：→ `#F3F1EA`。
3. 当前菜单项：→ `#E3E9E5`。
4. Hover：→ `#EDF1EE`。
5. 分隔线：→ `#D8DCD7`。
6. 主文字：→ `#252A2A`。
7. 次文字：→ `#656C69`。
8. 主按钮保持深色，使用 `#252A2A`；不要改成绿色按钮。
9. 运行状态、选中图标、图表点可使用 `#AFC2BC` / `#5D706C`。

## 第二阶段：统一密度

- Sidebar 当前项圆角固定 8px。
- 搜索框、按钮、高频输入统一 40px 高。
- 项目列表继续使用横向分隔，不改成卡片墙。
- 右侧运行次数与最近运行形成固定列宽。

## 第三阶段：加入苍渊主题

结构不变，只切换语义 Token。苍渊适合夜间训练、实时日志、GPU/容器监控、音频/模型可视化页面。

## 禁止重构方向

- 不要为了“品牌化”把 Sidebar 涂成深蓝或青绿。
- 不要给每个项目套独立阴影卡片。
- 不要增加蓝绿渐变 Hero。
- 不要使用鲜艳成功绿作为默认在线状态；状态颜色只在真实语义需要时出现。
