# UI 原则

## 1. 不是换皮，而是同一套信息语义

苍渊与白垣必须共享结构、间距、组件逻辑、信息层级。区别主要发生在颜色与光感，不允许两套主题长成两个产品。

## 2. 布局优先于卡片

- 优先使用：留白、分隔线、对齐、层级、密度。
- 少使用：悬浮卡片、厚阴影、玻璃拟态、超大圆角。
- 页面应像“工作台 / 仪器 / 档案系统”，而不是营销型 SaaS 卡片墙。

## 3. 几何规范

- 基准间距：8px。
- 控件高度：40px；紧凑模式 32px。
- 小圆角：6px；标准：8px；大容器最多 12px。
- Pill 只用于标签、状态和极少数过滤器；普通按钮不要全部胶囊化。
- 主边框：1px。
- 阴影应极轻；能用边框与明度解决就不用阴影。

## 4. 字体

推荐：

- 中文 UI：Noto Sans SC / 思源黑体 / 系统等线风格字体。
- 拉丁与数字：Inter / system-ui。
- 品牌海报与章节标题可少量使用 Noto Serif SC / 思源宋体。
- 产品 UI 内不使用尖锐、装饰性强的字体。

建议字号：

- 页面 H1：28–32px / 600
- 区块标题：18–20px / 600
- 正文：14px / 400
- 辅助：12–13px / 400
- 数据：24–32px / 500–600

## 5. 色彩分配

### 苍渊

建议视觉占比：

- 深渊/夜海：70–80%
- 铸铁：10–15%
- 星痕：5–10%
- 初光：通常 < 5%
- 星笺：用于主文字与必要标识，不作为大面积背景；上述比例用于背景与色块层级，不限制正文数量。

### 白垣

建议视觉占比：

- 石素/象牙：75–85%
- 雾青：8–12%
- 铜霜/垣影：3–8%
- 墨骨：作为文本与骨架广泛出现，但不是“色块装饰”。

## 6. 动效

- 默认 160–220ms。
- 动效体现“被识别 / 被建立”：线条亮起、边界浮现、状态从灰进入低饱和色相。
- 禁止霓虹扫描、频繁呼吸光、无意义粒子背景。

## 7. 图标

- 线性优先，1.5–2px 线宽。
- 18–20px 为常规尺寸。
- 不用彩色图标堆叠。
- 选中态通过背景与文字/图标色同步变化完成。
