# v1.1 决策锁

当前版本：v1.1。苍渊与白垣各含六个具名核心色。

## v1.1：星笺（2026-09-30）

- 将已有苍渊主文字色 `#E7EEF4` 命名为“星笺 / Starleaf”，纳入核心色。
- 新增基础 Token `primitives.abyssus.starleaf`、DTCG `color.abyssus.starleaf` 与 CSS `--av-starleaf`；既有语义 Token 名称与数值全部不变。
- 星笺承载可阅读、辨认与传递的知识；初光仍承担关键强调。星笺与墨骨分别支撑深浅主题的文字表达。
- 同步文化叙事、六色色卡与苍渊海报。既有五个苍渊色与全部白垣色不变。
- 迁移：现有组件无需改色或更名；使用固定五色枚举的工具需允许新增基础色。JSON `version` 更新为 `1.1`。
- 精确总色卡和苍渊色卡改为可直接核验填充值的 SVG，原同名 PNG 不再作为当前入口；引用方需更新扩展名。白垣色卡保持不变。
- v1.0 原始 Token 可从 Git 提交 `2b5082c` 获取；当前 Token 文件是 v1.1，不再称为原包逐字节快照。

后续变更仍须记录理由及迁移影响，不为普通作品自行改动锁定色值。

## 历史：v1.0

以下内容在 v1.0 内视为已定，不再进行“边做边调”：

1. 总名：苍渊·白垣。
2. 拉丁短名：ABYSSUS · VALLUM。
3. 深色主题名：苍渊 / Abyssus。
4. 浅色主题名：白垣 / Vallum。
5. 核心叙事：探索未知 → 建立并保存秩序。
6. 核心口号：探于苍渊，筑于白垣。
7. 苍渊五个核心色不变。
8. 白垣六个核心色不变。
9. UI 风格：极简、低卡片化、对齐优先、颜色低饱和。
10. 主设计原则：不要添加颜色，给灰色一点色相。

任何改动必须以 v1.1 / v2.0 的形式记录，并说明改动理由与迁移影响。
