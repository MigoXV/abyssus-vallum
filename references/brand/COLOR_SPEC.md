# 颜色规范（锁定）

本文件中的 HEX 与 `assets/tokens/` 完全一致。**未经版本升级，不允许在项目里自行“调一点点”。**

## 苍渊 / Abyssus

| 名称 | English | HEX | 语义 |
|---|---|---:|---|
| 深渊 | Abyss | `#080A0D` | 尚未被理解的世界；主背景 |
| 夜海 | Nocturne | `#111820` | 进入观察范围的未知边界；主要 Surface |
| 铸铁 | Forged Blue | `#273746` | 工程、结构、边界；边框与结构色 |
| 星痕 | Startrace | `#607D99` | 规律、路径、次强调、图表 |
| 初光 | First Light | `#9FC4E2` | 已确认的关键结果；最高等级强调 |
| 星笺 | Starleaf | `#E7EEF4` | 可阅读、辨认与传递的知识；主文字 |

### 苍渊规则

1. 初光不得大面积铺底；只用于真正重要的状态、主操作、焦点、曲线、关键数字。
2. 绝不使用高饱和宝蓝替代初光。
3. 黑色内部必须有层级：深渊 → 夜海 → 铸铁，而不是一片 `#000`。
4. 蓝色应像“冷光照到黑色表面”，而不是一块独立贴纸。

星笺沿用原有 `textPrimary` 色值，用于标题、正文和必要标识。它的高明度服务阅读，不代表高于初光的强调等级；关键操作与结果仍由初光突出。星笺不作为大面积浅色底使用。

## 白垣 / Vallum

| 名称 | English | HEX | 语义 |
|---|---|---:|---|
| 石素 | Pale Stone | `#F8F7F2` | 主背景；旧石之白 |
| 象牙 | Ivory | `#EEECE5` | 次级区域；温润的文明底色 |
| 雾青 | Patina Mist | `#DCE4E0` | 选中、Hover、轻强调 |
| 铜霜 | Verdigris Frost | `#AFC2BC` | 状态、图表、局部色相 |
| 垣影 | Rampart Shade | `#637774` | 结构阴影、较强的青灰强调 |
| 墨骨 | Ink Bone | `#252A2A` | 主文字、主按钮、骨架 |

### 白垣规则

1. 白垣不是纯白 + 薄荷绿，而是“旧石之白 + 岁月之青”。
2. 主背景固定使用石素 `#F8F7F2`，不要回退到刺眼 `#FFFFFF` 作为大面积页面底色。
3. 雾青和铜霜必须低饱和。禁止使用清新、糖果感、医疗感的薄荷绿。
4. 大面积交互按钮优先使用墨骨，而不是把按钮做成绿色。
5. 色相主要出现在选中、Hover、图表、状态、细线和局部高光。

## 统一原则

> **不要添加颜色。给灰色一点色相。**

- 视觉秩序来自中性色与排版，不来自彩色块。
- 颜色只负责“指出什么被理解、什么被选择、什么值得注意”。
- 大部分页面的第一视觉判断应是“灰黑/米灰”，第二眼才意识到其中有蓝或青。

## 功能状态色（例外）

真实产品仍需要表达错误、警告、成功。功能状态色可例外存在，但必须低饱和，并且只在状态语义真实存在时使用：

- Success：`#6F8F83`
- Warning：`#B09464`
- Danger：`#A96F74`
- Info：`#607D99`

禁止为了“丰富页面”而使用状态色。
